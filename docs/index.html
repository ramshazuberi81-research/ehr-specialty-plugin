Demo. Fake patients only, built into this page. Typed text stays on your device. The Speak button uses your browser's speech service, which may send audio to its provider. Saying a name is not authentication, and this is not for clinical use.
Simplified in-browser version of the EHR Specialty Filing plugin. The real plugin runs a FHIR server and, optionally, a language model; this page uses keyword matching and the same safety rules: it never guesses between two people with the same name, and missing information is shown as "not recorded".
